# Find Skills

Use `npx skills find [query]` to search for skills. Key commands:
- `npx skills find [query]` - Search for skills
- `npx skills add <package>` - Install a skill
- Check https://skills.sh/ for top skills

Always verify quality: prefer 1K+ installs, official sources (vercel-labs, anthropics).
